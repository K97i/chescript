Chescript is a script to automate adding features to a list of labelled words.

# How to Run:

If you have a Bash shell, run `./run.sh`. This will automatically run the command shown below.

Otherwise, `cd` to this folder and run:
```sh
python -m src.chescript
```

# How to add features:

Instructions on how to add features is in the [README.md in `./src/features`](./src/features/README.md).
